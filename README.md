# TinyPuzzle 🧩

纯前端网页拼图游戏：上传一张图片，在浏览器里把它变成你的拼图。图片全程本地处理，不上传任何服务器。

线上地址：<https://514215834.github.io/TinyPuzzle/>

## 功能

- 🖼️ 上传本地图片或选用内置示例图，随时随地开拼
- 🎚️ 难度自由配置：6 档预设（3×3 ~ 10×10）+ 自定义行列（2–10）
- 🧩 经典凹凸拼图块 / 方块两种形状，交换拼合 / 自由摆放两种玩法
- 🔄 旋转模式（≥25 块）：双击或长按旋转拼图块
- ⏱️ 计时、步数、按难度分档的本地最佳记录
- 👁️ 原图半透明参考、提示 ×3、吸附锁定开关
- 💾 刷新自动恢复进度（IndexedDB 本地缓存最近 5 张图片）
- 📱 移动端适配 + PWA 可安装、示例图离线可玩
- 📸 结算生成成绩分享图（本地 canvas 合成下载）

## 本地开发

```bash
npm install
npm run dev        # 开发服务器（base 为 /TinyPuzzle/）
npm test           # Vitest 单元测试（引擎层）
npm run build      # 类型检查 + 产物构建（dist/）
npm run preview    # 预览构建产物
```

## 部署（GitHub Pages）

1. 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**；
2. 推送到 `main` 分支即自动构建部署（工作流见 `.github/workflows/deploy.yml`）；
3. `vite.config.ts` 中 `base: '/TinyPuzzle/'` 与项目页子路径对应，迁移仓库时需同步修改。
