# TinyPuzzle 🧩

纯前端网页拼图游戏：上传一张图片，在浏览器里把它变成你的拼图。图片全程本地处理，不上传任何服务器。

线上地址：<https://514215834.github.io/TinyPuzzle/>

## 功能

- 🖼️ 上传本地图片或选用内置示例图（4 张实景图），随时随地开拼
- 🎚️ 难度按目标块数选择：500 / 1000 / 2000 块预设，或自定义 100–4000 块；行列按图片真实比例自适应（不裁剪、格子接近正方形，单边 2–220 格）
- 🧩 经典凹凸拼图块（真实蘑菇卡口造型）+ 自由摆放玩法，高清渲染（舞台 2048px + 拼图块 2~3 倍超采样）
- 🔍 拼图区域滚轮 / 双指缩放（0.5×–6×）、空白拖拽平移；散落场为棋盘 2 倍见方，散落块可停在任意空格
- 🔄 旋转玩法：Q / E 键左右旋转（拖拽中可用），触屏长按旋转
- 🔤 网格 A1 编码开关（默认关）+ 拼图双击翻面查看背面编码
- ⏱️ 计时、步数、按难度分档的本地最佳记录
- 👁️ 原图半透明参考、提示 ×3、吸附锁定开关
- 💾 刷新自动恢复进度（IndexedDB 本地缓存最近 5 张图片）
- 📱 移动端适配 + PWA 可安装、示例图离线可玩
- 🌐 中英双语切换、键盘无障碍操作
- 📸 结算生成成绩分享图（本地 canvas 合成下载）

## 本地开发

```bash
npm install
npm run dev        # 开发服务器（base 为 /TinyPuzzle/）
npm test           # Vitest 单元测试（引擎层）
npm run typecheck  # TypeScript 类型检查
npm run build      # 类型检查 + 产物构建（dist/）
npm run preview    # 预览构建产物
```

## CI 与部署（GitHub Pages）

- 推送到 `main` 或提交 PR 时，CI 自动执行类型检查 + 单元测试 + 构建（`.github/workflows/ci.yml`）；
- 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions** 后，推送到 `main` 即自动构建部署（工作流见 `.github/workflows/deploy.yml`）；
- `vite.config.ts` 中 `base: '/TinyPuzzle/'` 与项目页子路径对应，迁移仓库时需同步修改。

## 键盘操作（无障碍）

| 按键 | 作用 |
|---|---|
| 方向键 | 移动光标选择拼图块 |
| Enter / 空格 | 拾起 → 再按放置到光标格 |
| Q / E | 左旋 / 右旋（拖拽中可用，R 等效 E） |
| H | 提示 |
| Esc | 取消拾起 |

鼠标 / 触屏：滚轮或双指缩放、拖拽空白区域平移；触屏长按拼图块旋转；开启网格编码后双击拼图块翻面查看背面编码。
